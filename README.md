# Sales Performance Analysis with Excel

## Objective
Analyze 200 sample sales orders from 2025 to understand revenue, profit, regional performance, product/category mix, and monthly trends.

## Tools
Microsoft Excel, Excel Tables, formulas, charts, dashboard design.

## Workbook
Open `Sales_Performance_Analysis_Completed.xlsx` and review:
- `Dashboard` — KPI cards and charts
- `Analysis` — formula-driven summaries
- `Sales_Data` — source records

`SalesData.csv` is included as a portable copy of the dataset.

## Verified findings
- Total sales: ₹6,200,091.50
- Total profit: ₹1,104,777.66
- Units sold: 1,161
- Profit margin: 17.82%
- Top region: North (₹2,142,705.50)
- Top category: Electronics (₹4,605,265.00)
- Top product: Laptop (₹2,378,250.00)
- Best month: September (₹1,005,672.00)

## Reproduce
1. Open the workbook in Excel.
2. Check the three sheets listed above.
3. If you replace the dataset, keep the column names consistent and recalculate formulas.

## Data note
This is a sample portfolio dataset, not real company data. Results describe only the 200 rows included here.
